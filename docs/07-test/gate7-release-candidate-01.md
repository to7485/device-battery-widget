## Lifecycle result

- Self-contained `--smoke-seconds 5 --providers none`: PASS, exit code 0
- Framework-dependent `--smoke-seconds 5 --providers none`: PASS, exit code 0
- Duplicate launch while the RC primary instance was active: PASS; duplicate exited code 0 within
  three seconds and the primary remained active until its normal timed shutdown

The first RC smoke exposed an exclusive diagnostics-log collision with an older running instance.
Before distribution, startup was hardened in two ways:

1. v1.0.0 instances use a per-session named mutex and reject a duplicate launch cleanly.
2. If an older instance owns the diagnostics file, the new process removes/disposes the failed
   listener instead of recursively writing through it and crashing.

The rebuilt RC passed both lifecycle profiles and the explicit duplicate-instance test.
